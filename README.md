Java CRM – Desktop Customer Relationship Management System

This project is a Java-based desktop Customer Relationship Management (CRM) application developed using Core Java and JavaFX, focusing on managing customers, appointments,and business schedules efficiently. The application implements complete CRM functionality through Java logic, without using any web technologies. 

The system provides a secure login mechanism, customer management module, appointment scheduling with calendar views, and analytical reports. All business rules, validations, and workflows are handled entirely in Java, demonstrating strong object-oriented design and backend logic implementation.

🔹 Key Functionalities

User Authentication

Secure login and logout functionality

Customer Management

Add, update, delete, and view customer records

Manage customer address and contact details

Appointment Scheduling

Schedule appointments linked to customers

Start/end time validation and conflict handling

Calendar view for daily and monthly appointments

Calendar Management

View appointments by date and time

Navigate through appointment schedules

Reports Module

Appointment types by month (Rolling Year & Calendar Year)

User-based appointment statistics

Organization-level appointment analytics

Data Persistence

Database integration using JDBC

CRUD operations with proper validation and exception handling

🔹 Technologies Used

Java (Core Java)

JavaFX (Desktop UI)

JDBC (Database Connectivity)

MySQL (Relational Database)

MVC / Layered Architecture

Exception Handling & Input Validation

🔹 Project Objective

The objective of this project is to build a fully functional CRM desktop application using Java that manages customer relationships and appointment workflows in a structured and scalable manner. It serves as a real-world demonstration of Java application development, database interaction, and business logic implementation.

🔹 Learning Outcomes

Practical implementation of OOP concepts

Building JavaFX desktop applications

Handling real-world CRM workflows

Database design and JDBC integration

Implementing reports and time-based data analysis
